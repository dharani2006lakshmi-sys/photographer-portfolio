## 🚀 Features Overview

- **Lightning Fast:** Built with React and Vite for immediate load times even with heavy imagery.
- **Image Gallery:** Optimized, fully responsive image grid showcasing photography perfectly.
- **Modern UI:** Tailwind CSS powered sleek dark-mode design that makes photos pop.
- **Creative Focus:** Minimalist navigation ensuring the user's attention stays on the artwork.
